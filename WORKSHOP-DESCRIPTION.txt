[h1]Tesmio Clock — synchronized digital clock[/h1]

[b]Source code, releases and full English/Russian documentation:[/b]
[url=https://github.com/poltysik/tesmio-clock]https://github.com/poltysik/tesmio-clock[/url]

[h1]Important: this is an add-on, not a standalone mod[/h1]

[b]Tesmio Clock does not work on its own and does not replace a calendar synchronization mod.[/b]

It is a UI add-on for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3779646468]Calendar Synchronizer by Tesmio / MaxLegend[/url]. Install the original author's mod first.

Calendar Synchronizer controls calendar speed and the day/night cycle. Tesmio Clock adds a synchronized digital clock to the original Workers & Resources: Soviet Republic top HUD without opening a separate window.

[h1]Features[/h1]

[list]
[*]24-hour and 12-hour AM/PM variants.
[*]Time display updates in 30-minute steps.
[*]The calendar date changes exactly at midnight.
[*]Calibrated dawn, daylight, sunset and night display.
[*]Time and date share one clean field in the original top interface.
[*]The unnecessary vanilla calendar hover panel is removed.
[*]Automatic installer with clock-format selection.
[*]The format can be changed by running the installer again.
[/list]

[h1]Installation and updates[/h1]

1. Install TesmioLoader and Calendar Synchronizer.
2. Subscribe to Tesmio Clock and open its Workshop folder.
3. Run [b]INSTALL-TESMIO-CLOCK.bat[/b].
4. Select `1` for 24-hour or `2` for 12-hour AM/PM.
5. Start [b]tesmiolauncher.exe[/b], enable [b]TesmioClock.dll[/b] and press [b]Launch[/b].

The installer finds the game automatically, installs only the selected DLL and applies the tested Calendar Synchronizer settings. A backup of its configuration is created before any changes.

[b]Important:[/b] run [b]INSTALL-TESMIO-CLOCK.bat[/b] again after every Workshop update. Steam updates the Workshop folder but does not automatically replace a DLL already copied into TesmioLoader.

Do not enable the legacy [b]GameClock.dll[/b] together with [b]TesmioClock.dll[/b]. A new save is not required.

[h1]Calibration[/h1]

The tested configuration uses one calendar day per one full game day. Dawn begins around 05:00, daylight around 07:00, sunset around 20:00 and night around 22:00. The night part of the cycle may pass faster than daytime; this is normal Calendar Synchronizer behavior.

[h1]Установка и обновление[/h1]

1. Установите TesmioLoader и Calendar Synchronizer.
2. Подпишитесь на Tesmio Clock и откройте папку предмета Workshop.
3. Запустите [b]INSTALL-TESMIO-CLOCK.bat[/b].
4. Выберите `1` для 24-hour или `2` для 12-hour AM/PM.
5. Запустите [b]tesmiolauncher.exe[/b], включите [b]TesmioClock.dll[/b] и нажмите [b]Launch[/b].

Установщик автоматически найдёт игру, установит только выбранную DLL и применит проверенные настройки Calendar Synchronizer. Перед изменением конфигурации создаётся резервная копия.

[b]Важно:[/b] после каждого обновления повторно запускайте [b]INSTALL-TESMIO-CLOCK.bat[/b]. Steam обновляет папку Workshop, но не заменяет автоматически DLL, ранее скопированную в TesmioLoader.

Не включайте одновременно старый [b]GameClock.dll[/b] и [b]TesmioClock.dll[/b]. Новый мир не требуется.

[h1]Калибровка[/h1]

Рассвет начинается примерно в 05:00, светло становится около 07:00, закат начинается около 20:00, ночь — около 22:00. Ночная часть цикла может проходить быстрее дневной — это нормальная работа Calendar Synchronizer.
